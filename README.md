A small Python program that writes a one-line review of the most boring everyday object — a lint roller — to /output/entry.txt. The line never changes: every run produces the same 107-character line, in which a lint roller that peeled 3,000 of the cat Milo's hairs off a jacket still gets blamed for the one it missed.

## Run it

Run the script from the repo root — it validates the line, then writes it to /output/entry.txt:

```sh
python3 main.py
```
